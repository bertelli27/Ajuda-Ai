# Ajuda Aí

## Sobre o Projeto

O **Ajuda Aí** é uma plataforma web desenvolvida com o objetivo de conectar clientes que precisam de serviços com prestadores que oferecem esses serviços. A plataforma funciona como um intermediador digital, facilitando a comunicação, organização de solicitações e negociações entre as partes.

Este projeto está sendo desenvolvido como **Trabalho de Conclusão de Curso (TCC)** e encontra-se em desenvolvimento.

## Objetivo

O objetivo do sistema é:

* Permitir que clientes solicitem serviços
* Permitir que prestadores ofereçam serviços
* Criar comunicação entre cliente e prestador
* Organizar solicitações de serviços
* Permitir avaliações de prestadores
* Aumentar a confiança nas negociações entre usuários

## Tecnologias Utilizadas

### Front-end (em desenvolvimento)

* HTML
* CSS
* JavaScript
* LocalStorage (utilizado temporariamente para simulação de dados até a implementação do Back-end e Banco de Dados)

### Back-end (em desenvolvimento)

* Node.js

### Banco de Dados (em desenvolvimento)

* MySQL
